前言 INTRODUCTION

这是第四十一个千年…一百多个世纪以来，帝皇端坐在泰拉的黄金王座之上，纹丝不动。他是诸神意志下的人类之主，也凭借其麾下无穷无尽的军队统治着百万个世界。他是一具正在腐朽的尸体，在黑暗科技时代的力量下无法察觉地挣扎着。他是人类帝国的尸骸之主，每日都有一千个灵魂为他牺牲，这样他就永远不会真正死去。

即便处于这不朽之躯中，帝皇仍保持着永恒的警惕。强大的战斗舰队穿过恶魔滋生的亚空间瘴气，那是遥远群星之间唯一的航路。星炬（Astronomican）为它们指引方向，这是帝皇意志的灵能显现。庞大的军队以他的名义在无数世界上投入战斗，这其中最为伟大的是阿斯塔特修会（Adeptus Astartes）——星际战士（Space Marine），由生物工程技术打造而成的超级战士。他们的战友更是数量众多：帝国卫队（Imperial Guard）与数不胜数的行星防御部队，时刻警戒的审判庭（Inquisition）和机械修会（Adeptus Mechanicus）的技术神甫（Tech-Priests），这还仅仅只是其中的一部分。但是即便拥有如此强大的力量，他们也只能勉强抵抗永续存在的威胁：异形、异端、变种人（mutants）——甚至更加糟糕的敌人。

诞生于这样的时代，意味着你只是无可计数的亿万众生之一，生活在人类所能想象的最残酷、最血腥的统治之下。忘却科学与技术的力量吧，因为太多知识早已遗忘，永不复得。忘却进步与理解的许诺吧，因为在遥远未来的黑暗时代，唯有战争。群星之间并无和平，只有永恒不息的杀戮与饥渴众神的嘲笑声。
